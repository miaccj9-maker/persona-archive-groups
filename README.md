# 面具合并存档（按角色分组）

把酒馆「用户设定管理」左栏改成**按角色管理面具**的工作台。

## 功能
- 列出**角色库中的全部角色**，每个角色一个折叠存档夹：
  - 连接到该角色的面具列在夹内；
  - 没有连接任何面具的角色也会显示，标注「0 个面具」。
- 夹内底部有「从已有面具绑定到本角色」按钮，点一下弹出面具选择器，选一个就直接连上（已连的高亮）。
- 点组头右侧铅笔可给存档夹起备注名（留空恢复角色名）。
- 排序：有面具的角色在前，空角色在后；未连接任何角色的面具归在最后的「未绑定角色」。
- 搜索框按名字/描述过滤；默认展开当前面具所在分组。

## 稳定性
- 只改左栏展示：面具卡片克隆原生模板，点选、选中态沿用原生事件委托。
- 绑定/解绑直接读写酒馆原生 `persona_descriptions[id].connections`，与官方「链接→角色」数据完全一致，不另起炉灶。
- 渲染用 DocumentFragment + 防抖 + 重入锁；扩展设置里可一键关闭，恢复原生平铺。

## 使用
放到 `data/default-user/extensions/`，刷新酒馆即可。
